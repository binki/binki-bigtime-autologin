Automatically login to bigtime.

The BigTime login requires clicking through two screens. It often logs you out even if you specify remember, especially on mobile. This clicks through those screens for you.

Note: For this to work properly, the password manager entry for your account must exactly match the domain you are using to login. Otherwise, instead of prefilling the password box, Firefox will simply provide a drop-down which requirse user interaction. BigTime has changed which domains it uses for login over time. **Ensure that you have exactly 1 password entry for `app.bigtime.net`.** Remove any entries you had for `intuit.bigtime.net` or `iq.bigtime.net`.
